One original one-line dad joke, written by a tiny stdlib-only Python program.

## The joke

> I asked the gym for a dad-bod membership. They said, 'Sir, that's just a membership.'

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (1–140 characters, per the gate).
No network, no dependencies, no input files.
